# Getting help

SwiftCode is a volunteer project in public beta, so help is best effort.

| You want to | Go to |
|---|---|
| Install or try SwiftCode | The [README](README.md#install) and the [documentation](docs/README.md) |
| See whether a feature exists | The [feature table](README.md#what-works-today), or the full [parity audit](docs/PARITY.md) |
| Report a bug | [A bug report](https://github.com/dylans2010/SwiftCode-Mac/issues/new?template=bug_report.yml) |
| Report a simulator problem | [A simulator report](https://github.com/dylans2010/SwiftCode-Mac/issues/new?template=simulator_report.yml) |
| Suggest a feature | [A feature request](https://github.com/dylans2010/SwiftCode-Mac/issues/new?template=feature_request.yml) |
| Ask a question | [An issue](https://github.com/dylans2010/SwiftCode-Mac/issues), after a search for an existing answer |
| Report a security problem | [SECURITY.md](SECURITY.md), and please not a public issue |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

## What helps us help you

Say which version you run, on which system and architecture, and how you installed it. Include the steps to reproduce
the problem and what you saw. A small project that shows the problem is the best report of all.

**Please don't attach Apple files** (SDKs, runtimes, Xcode resources), and check logs for private paths and names first.

## What we can't help with

- Problems in Xcode or Apple's tools themselves. SwiftCode isn't affiliated with Apple, and Apple can't help with SwiftCode either.
- Getting or licensing Apple's software. SwiftCode never ships it, and we can't send it to you.
