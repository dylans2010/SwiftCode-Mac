# Swift Development Skill

## Guidelines
- Follow Swift 6 Concurrency best practices (@MainActor, Sendable, actors).
- Avoid blocking the main UI thread during intensive I/O or background compilation.
- Ensure all file modifications are checked with syntax validation.
- Preserve existing documentation, comments, and architecture patterns.
